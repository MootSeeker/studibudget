# StudiBudget-Vault

Obsidian-Vault zum Projekt StudiBudget. Er liegt im Repository unter `vault/` und ist deshalb **öffentlich**: keine
Schlüssel, Passwörter, Tokens oder persönlichen Daten hineinschreiben.

Öffnen: In Obsidian «Ordner als Vault öffnen» und `vault/` wählen. Einstieg: [Start](Start.md).
